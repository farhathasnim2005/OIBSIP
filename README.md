# OASIS INFOBYTE — Python Programming Internship

## Task 1: Voice Assistant

### Project Description
This project is a simple voice assistant developed using Python. It listens to voice commands, responds using speech, provides the current time and date, opens websites, and searches Google for user questions.

### Features
- Voice input using SpeechRecognition
- Text-to-speech using pyttsx3
- Greeting responses
- Current time and date
- Open Google and YouTube
- Search Google using voice commands
- Basic error handling

### Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- PyAudio
- datetime
- webbrowser

### Installation

Install the required libraries:

```bash
python -m pip install SpeechRecognition pyttsx3 pyaudio
```

### How to Run

Run the following command in the terminal:

```bash
python main.py
```

### Example Commands
- Hello
- How are you?
- What is the time?
- What is today's date?
- Open Google
- Open YouTube
- Search Python tutorial
- Exit
