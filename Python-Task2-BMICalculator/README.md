# OASIS INFOBYTE – Python Programming Internship

## Task 2: BMI Calculator

### Project Description
The BMI Calculator is a Python application that calculates Body Mass Index using a person's weight and height.

### Features
- Accepts weight in kilograms
- Accepts height in centimeters
- Calculates BMI
- Displays the BMI category
- Handles invalid and non-positive inputs

### Technologies Used
- Python 3
- Conditional statements
- Functions
- Exception handling

### How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python main.py
```

### BMI Categories
- Below 18.5: Underweight
- 18.5 to below 25: Normal weight
- 25 to below 30: Overweight
- 30 and above: Obese

These are general adult screening categories, not a medical diagnosis.
